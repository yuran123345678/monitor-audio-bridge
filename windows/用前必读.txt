音频桥 · Windows 端
====================

怎么开
------
双击 AudioBridge.exe。
（如果没有这个文件，或者打不开：双击「启动.bat」，它会用 Windows 自带的编译器现编一个，几秒钟。
  需要 .NET Framework 4，Win10/11 自带。不用装别的东西，不要管理员权限。）

第一次运行会弹 Windows 防火墙：勾上「专用网络」，点允许。
不允许的话：别的电脑发现不了这台，这台也收不到声音（往外发不受影响）。

怎么用
------
右上角选角色：

  接收 —— 这台电脑出声。打开后等着就行，状态显示「等待发送端」。
          也可以主动要：点「选择发送端…」，列出局域网里允许被拉取的电脑，点一台拉过来
          （第一次对方那边要点一下「允许」）；想断开就点「取消拉取」。
          打开「同时接收多路」可以最多 4 台一起出声。

  发送 —— 把这台电脑正在放的声音送出去。在「发送到」里点对方的名字。
          别人也可以主动来拉：打开「允许其它设备拉取」，第一次会弹窗问你是否同意，
          同意过的设备记在「受信任设备」里，以后不再问。
          「丢包冗余」在 Wi-Fi 不稳时打开：每包多带一份上一包的副本，流量翻倍但不卡。
          「采集来源」默认跟随系统的默认播放设备；选「按程序采集…」可以只送某个程序的声音
          （需要 Windows 10 2004 或更新，旧系统会自动退回整机采集）。

状态显示「正在发送 / 正在接收」、电平表在跳，就是通了。
勾上「登录时自动启动」之后，开机会自动连回上次那台，不用再管。

点窗口的 × 只是收进右下角托盘，程序还在跑。托盘图标右键 →「退出音频桥」才是真退。
快捷键：空格 开始/停止 · M 静音 · ←→ 音量 · Esc 收进托盘。

常见情况
--------
· 「对方没有回应」
    对方没开音频桥、没切到「接收」、防火墙没放行，或者两台不在同一个网络。
    这时声音其实一直在发，对方一就绪会自动接上，不用重新点。

· 列表里看不到对方
    多半是防火墙或路由器不让广播通过。直接手动填 IP 一样能用。
    公司/酒店/校园 Wi-Fi 常开「客户端隔离」，两台设备互相完全不通，只能换网络或开手机热点。

· 声音断断续续
    把对方（接收端）的缓冲从「低延迟」换成「自动」或「稳定」；尽量用 5 GHz Wi-Fi 或网线。

· 这台当发送端时，自己的音箱也在响
    Windows 上没法只送不响。把默认播放设备设成显示器（HDMI/DP），再把显示器音量拧到 0，
    数字信号照常走，对方照样能收到。

· 声音比画面慢一点
    正常，局域网传输加缓冲大约 50–70 毫秒。看视频基本无感；打游戏选「低延迟」。

· 换了耳机 / 换了默认播放设备
    不用管，一秒内自动跟过去。

· 改了源码（.cs 文件）
    先从托盘退出，再双击「重新编译.bat」。

· 出了怪问题
    把这个文件发给开发者：%APPDATA%\AudioBridge\error.log
    （在资源管理器地址栏粘贴 %APPDATA%\AudioBridge 回车就能看到）
    设置存在同一个文件夹的 settings.ini 里，删掉它等于恢复默认。

注意
----
· 声音不加密，只在自己家的网络里用。
· 端口：47831/udp（声音）、47832/udp（发现设备）。

· 第一次运行时 Windows 拦了一下
    安装包没有代码签名证书，SmartScreen 会提示「Windows 已保护你的电脑」：
    点「更多信息」→「仍要运行」。之后不会再拦。
