音频桥 3.0.2 · macOS 通用版（Intel + Apple 芯片），需要 macOS 14.2 或更新

一、安装
  把左边的「音频桥」拖进右边的 Applications（应用程序）文件夹。

二、第一次打开
  这个包没有 Apple 开发者签名和公证，系统会拦一下，任选一种：

  1) 在「应用程序」里右键点「音频桥」→ 打开 → 再点弹窗里的「打开」。
  2) 或者打开终端，执行：
       xattr -dr com.apple.quarantine "/Applications/音频桥.app"
     之后正常双击即可。

三、首次运行会申请两个权限
  - 「允许查找本地网络设备」→ 允许（不答应就发现不了另一台电脑）
  - 「录制系统音频」→ 允许（不答应只是发出去是静音，界面会提示）

四、使用
  两台电脑都要打开这个程序，一台切「发送」、一台切「接收」，
  在「发送到」列表里点对方即可。也可以让接收端「选择发送端…」主动拉流。

五、卸载
  把「音频桥」从 Applications 拖进废纸篓即可。偏好设置在
  ~/Library/Application Support/MonitorAudioBridge/，需要时手动删。
